# 白模风险与材质恢复建议

这份检查针对你截图里提到的 KidRoom/家具资源。结论是：有些灰白缩略图不是复制导致，而是原始 FBX 的材质名、材质搜索范围或导出时的默认 `lambert` 材质导致 Unity 没有办法自动找到对应 `.mat`。

## 本地检查结果

- 原始男孩房 FBX 风险项：8 个。
- 原始女孩房 FBX 风险项：2 个。
- 筛选目录中仍有明确材质名缺失：0 个。
- 筛选目录中只检测到导出默认材质名 lambert/lambert1 的模型：0 个；这类需要人工判断是否用默认灰白，还是给它手动指定更合适材质。

## 已在筛选目录修正

- 已把 KidRoom FBX 按原包结构放回 `ROOM_BOY/MESH/Materials` 或 `ROOM_GIRL/Mesh/Room_KID/Materials`。
- 已复制 FBX 的导入设置 `.meta`，只重写 GUID，保留材质导入/搜索设置。
- 已补齐能自动判断的跨包材质/别名，例如 `MAT_Cooking_AlbedoTransparency`、`MAT_LightCeiling`。

## 原始资源中发现的典型问题

| 类型 | 例子 | 说明 | 建议 |
|---|---|---|---|
| 材质名跨目录 | `SM_Room_Light_Ceiling.fbx` 需要 `MAT_LightCeiling`，但女孩房 Materials 里没有这个精确名字 | 材质在另一个房间包里或名字略不同 | 把同名材质复制到本模型旁边的 `Materials`，或在 Remapped Materials 手动指定 |
| 材质名不完全一致 | `MAT_Matelas3` 这类名字找不到精确 `.mat` | FBX 内部材质名和资源包 `.mat` 名不完全一致 | 复制最接近的材质并改名为 FBX 要找的名字，或手动 Remap |
| 只有默认 lambert | `SM_Room_Tapis.fbx` 这类只暴露 `lambert1` | 导出时没有保留具体材质名，Unity 只能生成/使用默认材质 | 手动给它指定地毯/布料材质；这种无法完全自动判断 |
| 材质本身就是白/灰 | 椅子、长凳、插座、灯开关等 | 缩略图白灰不一定是坏，有些对象本来就是白色塑料/灰色金属 | 拖进场景看实际材质槽和贴图，不要只看缩略图 |

## 通用恢复办法

1. 选中 FBX，在 Inspector 的 Materials 页签里，把 Naming 设为 From Model’s Material 或按现有导入设置保持，再把 Search 改为 Local Materials Folder / Recursive-Up / Project-Wide 中更合适的一项，然后点 Search and Remap。
2. 如果 Remapped Materials 里仍然空白，把缺失名字对应的 `.mat` 放到模型旁边的 `Materials` 子文件夹里，文件名最好和 FBX 内部材质名完全一致。
3. 如果 FBX 只显示 `lambert` / `lambert1`，说明导出文件里没有足够的材质名信息，通常要手动拖一个合适材质到 Remapped Materials。
4. 如果模型里有嵌入材质或贴图，可在 Materials 页签使用 Extract Materials / Extract Textures，把它们提取出来再重映射。
5. 如果只是 Project 视图缩略图灰白，先 Reimport；最终以拖入场景后的 Mesh Renderer 材质槽为准。
