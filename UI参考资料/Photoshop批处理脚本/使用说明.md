# Photoshop 混合颜色带批处理脚本

这两个脚本用于把图层的“混合选项 > 混合颜色带”统一设置为截图里的数值：

- 混合颜色带：灰色
- 当前图层：黑场分离为 `59 / 125`，白场 `255 / 255`
- 下一图层：黑场 `0 / 0`，白场 `255 / 255`

## 文件

- `Apply_BlendIf_59_125_ActiveLayerOnly.jsx`：只处理当前选中的一个图层，建议先用它测试效果。
- `Apply_BlendIf_59_125_AllArtLayers.jsx`：批量处理当前 PSD 内所有普通图层，包括组里的图层；会跳过 Background 和完全锁定的图层。
- `Apply_BlendIf_59_125_AllArtLayers_NoDialog.jsx`：无弹窗版本，给 Codex 或自动化调用用；结果写入 `BlendIf_NoDialog_Log.txt`。
- `Export_AllArtLayers_To_Desktop_PNG_NoDialog.jsx`：把当前文档的普通图层逐个导出为透明 PNG，并在桌面创建输出文件夹。

## 使用方式

1. 在 Photoshop 里先另存一份 PSD 备份。
2. 打开目标 PSD。
3. 先选中一个 UI 图层。
4. 菜单选择 `文件 > 脚本 > 浏览...`，运行 `Apply_BlendIf_59_125_ActiveLayerOnly.jsx`。
5. 如果效果正确，再运行 `Apply_BlendIf_59_125_AllArtLayers.jsx` 批量处理。

脚本不会合并图层、不会栅格化文字、不会删除像素，只是给图层套 Blend If 参数。
