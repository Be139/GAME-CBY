# 《已为您沟通》场景物件缺口与资产补充建议

## 当前已有资源概况

现有 `Assets/家具筛选` 已覆盖大量住宅家具和软装：客厅沙发、茶几、电视柜、餐桌椅、主卧床柜、儿童房家具、厨房家电、浴室洗衣、灯具、书籍办公、阳台户外家具、装饰摆件、小物、公共区家具等。

现有资源的强项是“把房间填起来”：可用于快速完成住宅和公共区的基础布置。

现有资源的弱项是“把主题讲清楚”：门禁、同步系统、公共区管理、夜间托管、家庭矛盾、智能社区、17F走廊压迫感等主题性物件还不够。

## 建议新增的本地分类文件夹

| 建议文件夹 | 放什么 | 是否已有可用源资源 |
|---|---|---|
| `通用_门窗门禁` | 门、门框、门锁、门牌、门铃、窗锁 | LowPolyInterior 有 Door_01 到 Door_05，可先整理；智能门锁需要外部补 |
| `通用_智能终端屏幕` | 墙面屏、桌面屏、全息屏、家庭中控、同步提示屏 | 现有电视/电脑可临时代替；主题终端建议外部补 |
| `17F公共区_电梯导视门禁` | 电梯门、楼层屏、按钮、门禁、楼层号、公告栏 | 电梯相关缺口较大，建议外部补 |
| `17F公共区_安全物业设备` | 摄像头、烟感、灭火器、消防箱、弱电箱、清洁工具 | 本地有少量信息面板，但安全设备不足 |
| `通用_生活痕迹剧情小物` | 鞋、包、快递、药盒、照片、账单、作业、便签 | 本地有书、杯子、相框；更叙事的小物不足 |
| `通用_儿童青少年线索` | 身高尺、奖状、课程表、夜灯、涂鸦、贴纸 | 现有玩具较多，墙面线索不足 |

## 最建议下一步

先不要继续大量买包。最有效的是先在本地新增三个筛选目录：

1. `通用_门窗门禁`
2. `通用_智能终端屏幕`
3. `17F公共区_安全物业设备`

这三类一补上，游戏主题会比单纯增加沙发、床、柜子明显很多。
