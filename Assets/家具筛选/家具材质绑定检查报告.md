# 家具筛选材质绑定检查报告

本报告用于记录对 `Assets/家具筛选` 的二次排查结果，重点检查复制后是否会出现模型变灰、白模、材质贴图丢失等问题。

## 检查结论

- 当前筛选目录总量：1692 个 prefab、424 个 FBX、1166 个配套材质球。
- 2026-06-08 新增包：`HQ_ResidentialHouse`、`Kitchen Collection 2`、`TM's Living Room Interior` 已新增归档 1097 个条目。
- FBX 模型：424 个，全部有 `.fbx.meta`；新增 FBX 已复制原导入设置并改用新 GUID。
- 新增 prefab/FBX 风险扫描：未发现空材质 GUID `00000000000000000000000000000000`，也未发现 `m_Materials: []` 空材质数组。
- KidRoom FBX：已按原包结构放置到 `ROOM_BOY/MESH/Materials` 或 `ROOM_GIRL/Mesh/Room_KID/Materials`，避免模型和材质平铺后 Unity 找不到材质。
- Prefab：本轮新增 prefab 保留原资源 GUID 引用，拖入场景时仍会使用原包中的模型和材质。
- LowPolyInterior：558 个 prefab 使用 `LowPolyInterior_MAIN.mat` / 同类统一材质包，已在对应分类的 `_配套材质` 中复制这些材质。
- 配套材质球：复制件用于检查和替换；材质球本身继续引用原贴图，不重复搬运贴图。
- 9 个 prefab 中存在 Unity 内置默认材质占位 GUID `0000000000000000f000000000000000`，这是内置占位，不是 Assets 中的丢失材质；这些 prefab 同时仍有正常材质引用。

## 已修复的问题

- 上一版把 KidRoom 的 `.fbx` 和 `.mat` 平铺到同一分类目录，Unity 重新导入 FBX 时容易丢掉本地材质搜索关系。
- 现在已改为保留原包层级，并复制 FBX 导入设置 `.meta`，只重写 GUID，避免和原资源冲突。
- Prefab 的配套材质不再混在分类根目录，而是放进 `_配套材质`，减少翻找家具时的干扰。

## 仍需在 Unity 中注意

- 如果 Unity 仍显示旧灰色缩略图，右键 `Assets/家具筛选` 执行 Reimport。
- Prefab 拖入场景时仍引用原资源 GUID；旁边 `_配套材质` 是检查/替换用，不会自动改写 prefab 引用。
- FBX 的材质恢复依赖 Unity 的本地材质搜索，已经尽量保持原结构，但如果个别模型仍灰，需要在 Inspector 中用 Remapped Materials 手动确认。
